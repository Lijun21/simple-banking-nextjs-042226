# simple-banking-nextjs-042226

Code up an app:

Company P help small to medium size businesses to pay with credit card to vendors doesnn't accept credit cards

customers pay with credit card to Company P account, via web app
Company P pay to vendors via ach, wire or check, charge a fee
customers can view all payment transactions
once a payment is complete, send a email to the customer and the vendor.

Front end: React, Typescript, NextJS
Back end: Node, Typecsript, NestJS, PostgreSQL, Redis
